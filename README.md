# 🌱 Weed Detection using YOLOv11

## 📌 Project Overview
This project detects weeds in agricultural fields using a YOLOv11 object detection model.

It can:
- Train a model on weed datasets
- Detect weeds in images/videos
- Convert video → frames → detection → output video

---

## ⚙️ Tech Stack
- Python
- PyTorch
- Ultralytics YOLO
- OpenCV

---

## 🚀 How to Run

### 1. Install dependencies

pip install -r requirements.txt


### 2. Train model

python train.py


### 3. Test model

python test.py
